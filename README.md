# Perbandingan Algoritma Apriori dan FP-Growth

## Deskripsi
Website ini dikembangkan untuk membandingkan algoritma Apriori dan FP-Growth dalam menganalisis pola transaksi penjualan. Sistem ini bertujuan menemukan kombinasi produk yang sering dibeli secara bersamaan berdasarkan data transaksi serta menghasilkan aturan asosiasi (*association rules*).

Melalui aplikasi ini, pengguna dapat mempelajari penerapan kedua algoritma dalam proses data mining untuk mengidentifikasi pola pembelian pelanggan dan memperoleh informasi yang dapat membantu pengambilan keputusan terkait strategi penjualan.

## Tujuan
- Menerapkan algoritma Apriori dan FP-Growth untuk menganalisis data transaksi penjualan.
- Menemukan kombinasi produk yang sering muncul secara bersamaan.
- Mengidentifikasi pola pembelian pelanggan berdasarkan data transaksi.
- Menghasilkan aturan asosiasi menggunakan nilai support dan confidence.
- Membandingkan hasil analisis yang diperoleh dari kedua algoritma.

## Fitur Utama
- Pengolahan data transaksi penjualan.
- Analisis pola transaksi menggunakan algoritma Apriori.
- Analisis pola transaksi menggunakan algoritma FP-Growth.
- Pencarian frequent itemsets.
- Pembentukan aturan asosiasi (*association rules*).
- Penyajian hasil analisis untuk membantu perbandingan kedua algoritma.

## Algoritma yang Digunakan

### 1. Apriori
Apriori merupakan algoritma data mining yang digunakan untuk menemukan kombinasi item yang sering muncul dalam kumpulan transaksi. Algoritma ini menggunakan prinsip bahwa suatu kombinasi item hanya dapat menjadi frequent itemset apabila seluruh subset-nya memenuhi ambang minimum support.

### 2. FP-Growth
FP-Growth merupakan algoritma data mining yang digunakan untuk menemukan frequent itemsets melalui struktur data FP-Tree. Algoritma ini tidak memerlukan proses pembentukan kandidat itemset secara berulang seperti pada Apriori.
